# 一级标题：文章内的最高层级

一级标题适合文章内部极少数需要重新建立阅读起点的部分。页面顶部的文章标题仍是整页最高层级，因此正文中不宜频繁使用一级标题。

## 二级标题：文字层级

一篇长文首先需要稳定的阅读节奏。普通正文可以包含 **加粗文字**、_强调文字_、**_加粗且强调_**、~~被删除的文字~~、[行内链接](https://tung.mockingbird.team)、[引用式链接][site]，以及像 `layout="wide"` 这样的行内代码。裸网址也会自动成为链接：https://mockingbird.team。

反斜杠可以显示原本具有语法作用的字符，例如 \*星号\*、\# 井号与 \[方括号\]。

[site]: https://tung.mockingbird.team 'Tung’s'

行内链接把地址直接写在正文里；引用式链接把地址集中定义。两者最终生成的网页链接相同，引用式写法更适合多次复用同一地址。

```md
一篇长文首先需要稳定的阅读节奏。普通正文可以包含 **加粗文字**、_强调文字_、**_加粗且强调_**、~~被删除的文字~~、[行内链接](https://tung.mockingbird.team)、[引用式链接][site]，以及像 `layout="wide"` 这样的行内代码。裸网址也会自动成为链接：https://mockingbird.team。

反斜杠可以显示原本具有语法作用的字符，例如 \*星号\*、\# 井号与 \[方括号\]。

[site]: https://tung.mockingbird.team 'Tung’s'
```

<Sidenote label="边注">
  边注用来补充一条值得保留、但放进正文会打断叙事的信息。桌面端让正文环绕它，窄屏则自然落回文流。
</Sidenote>

这一段特意接在边注之后。边注不是正文的另一个标题，也不是必须阅读的脚注；它更像作者在页边轻声补上的一句话。

```mdx
<Sidenote label="边注">
  边注用来补充一条值得保留、但放进正文会打断叙事的信息。桌面端让正文环绕它，窄屏则自然落回文流。
</Sidenote>
```

### 三级标题：一个叙事单元

三级标题适合区分一个章节里的不同动作或视角。再往下的标题仍然可用，但应该节制。

#### 四级标题：一个局部问题

四级标题仍然承担可见的结构作用。

##### 五级标题：一个操作步骤

五级标题更接近段内标签。

###### 六级标题：微小的分类标记

六级标题最轻，也最不适合承载长句。

```md
# 一级标题：文章内的最高层级
## 二级标题：文字层级
### 三级标题：一个叙事单元
#### 四级标题：一个局部问题
##### 五级标题：一个操作步骤
###### 六级标题：微小的分类标记
```

## 列表、任务与表格

无序列表可以保持信息的松散关系：

- 从一个观察开始；
- 保留材料中的犹豫；
- 在下结论以前先组织证据。
  - 子项可以解释条件；
  - 也可以列出例外。

```md
- 从一个观察开始；
- 保留材料中的犹豫；
- 在下结论以前先组织证据。
  - 子项可以解释条件；
  - 也可以列出例外。
```

有序列表适合真正存在先后关系的流程：

1. 写下正文；
2. 插入图片和图注；
3. 在发布前检查移动端。

```md
1. 写下正文；
2. 插入图片和图注；
3. 在发布前检查移动端。
```

定义式关系目前用普通列表表达；Markdown 的重点是保持源文件可读，而不是复制文字处理软件的每一种控件。

任务列表则适合临时维护文章：

- [x] 完成初稿
- [x] 核对图片来源
- [ ] 发布前删除这条提醒

```md
- [x] 完成初稿
- [x] 核对图片来源
- [ ] 发布前删除这条提醒
```

| 边注 | 可跳过的补充信息 | 关键结论     |

## 提示块与拉引文

提示块用于不会折叠、又不应混进连续正文的信息。三种类型表达不同功能，而不是单纯更换颜色。

<Callout type="note" title="写作提示">
  普通提示记录读者可能需要立即知道的补充条件。
</Callout>

<Callout type="context" title="语境">
  语境块适合交代一段历史背景、概念来源，或面向另一文化背景读者的解释。
</Callout>

<Callout type="warning" title="注意">
  警示块只用于确实可能造成误解、数据丢失或操作风险的内容。

```md
---
```
